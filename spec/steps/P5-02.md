# P5-02 — Table context menu

- **Linear:** SAD-42
- **Phase:** P5 — Right-click (see `spec/phases/P5.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P5-02)

- **Objective:** Cell, row, and header menus work, are undoable where expected, and are keyboard accessible.
- **Prerequisites:** P3-06, P1-05, P2-03.
- **Actions:**
  1. Cell: Copy, Paste, Clear.
  2. Row: Insert above, Insert below, Duplicate, Copy, Delete.
  3. Header: Change field type, Hide field, Sort ascending, Sort descending, Freeze column.
  4. Items that do not apply are hidden or disabled with a reason shown.
  5. Open with right-click and with the keyboard menu key or Shift+F10.
- **Dependencies:** P3-06, P1-05, P2-03.
- **Outputs:** `src/menus/tableMenu.ts`, tests.
- **Verification:**
  - T-E: each item, once, with the file checked after.
  - T-E: each undoable item undone with Ctrl/Cmd+Z and the file matches the original.
  - T-E: keyboard-only open and use.
  - T-E: disabled items show a reason.
- **Performance:** Menu opens < 100 ms (proposed).
- **Acceptance:** All checks pass with evidence.
