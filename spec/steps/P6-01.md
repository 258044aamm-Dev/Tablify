# P6-01 — Test matrix

- **Linear:** SAD-44
- **Phase:** P6 — Hardening and release (see `spec/phases/P6.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P6-01)

- **Objective:** All MVP acceptance scenarios (A1–A11 in `ROADMAP.md` §10) pass on every target.
- **Prerequisites:** All MVP steps (P0–P5) accepted.
- **Actions:**
  1. Create `docs/testing/matrix.md`: scenario × platform grid. Platforms: Windows, macOS, Linux, iOS, Android.
  2. Record the Obsidian version on each platform.
  3. Run every scenario. Attach evidence (screenshot, file diff, or log).
  4. Log every failure as an issue. Fix and re-run the affected scenario and its regressions.
- **Dependencies:** all MVP steps.
- **Outputs:** Matrix results, evidence folder, issue records.
- **Verification:** Matrix complete with no empty cells. Each cell marked PASS, FAIL (linked issue), or NOT RUN (reason).
- **Performance:** N/A (performance is in P6-02).
- **Acceptance:** A1–A11 pass on all five platforms, or NOT RUN cells are accepted by the owner with a reason. No S1 or S2 open.
