- **Objective:** Exports match what the user sees, in CSV, XLSX, and Markdown.
- **Prerequisites:** P2-02, P1-03.
- **Actions:**

  2. CSV: RFC 4180 quoting; same file as the P4-01 format.
  3. XLSX: writer chosen in P4-02.
  4. Markdown: escape `|` and newlines in cells.
- **Dependencies:** P2-02, P1-03, P4-02.
- **Outputs:** `src/io/export/*`, tests.
- **Verification:**
  - T-D: export to CSV, then parse with the P4-01 parser and the reference library. Results equal the on-screen rows (compare by script).
  - T-I: XLSX export opened by a second reader; values match.
  - T-U: Markdown escaping cases.
  - T-P: PERF-7 for FX-M.
- **Performance:** PERF-7.
- **Acceptance:** Comparisons show zero mismatches. PERF-7 met.
