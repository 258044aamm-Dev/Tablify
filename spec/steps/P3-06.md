# P3-06 — Keyboard navigation and shortcuts

- **Linear:** SAD-33
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P3-06)

- **Objective:** Every grid action works from the keyboard, with no conflict with Obsidian's default hotkeys.
- **Prerequisites:** P3-02, P1-05.
- **Actions:**
  1. Arrows, Tab, Shift+Tab, Enter, Escape.
  2. Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z for undo and redo.
  3. Ctrl/Cmd+C and Ctrl/Cmd+V on cell ranges. Clipboard uses tab-separated text, so it pastes into spreadsheets.
  4. Shortcuts apply only when the grid has focus.
  5. Compare the list of shortcuts against Obsidian's default hotkeys and document any overlaps.
- **Dependencies:** P3-02, P1-05.
- **Outputs:** `src/views/grid/keyboard.ts`, shortcut table in `docs/shortcuts.md`.
- **Verification:**
  - T-U: key event handler maps each key to the expected action.
  - T-E: scripted run of every shortcut on desktop; record results.
  - T-E: copy from grid, paste into a text editor; the result is tab-separated and matches the cells.
  - T-E: shortcut fired inside a note pane does not change the grid.
- **Performance:** Keystroke to visible response < 50 ms (proposed).
- **Acceptance:** All shortcuts tested. Overlap list recorded.
