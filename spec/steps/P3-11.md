# P3-11 — Contrast and visual verification (desktop and mobile)

- **Linear:** SAD-67
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/branding.md` §5, `spec/guidelines.md` §0 and §1
- **Source:** written for this spec from `spec/branding.md` §5 (accessibility rule) and open item G-B1. Not in the guideline file.

- **Objective:** Every text and UI element meets WCAG 2.1 AA in both themes. The visuals are checked on desktop and on mobile.
- **Prerequisites:** P3-09, P3-10, P3-01 (grid rendered).
- **Actions:**
  1. Compute the contrast ratio for every text and background pair in both themes.
  2. Use the orange and green accents as text only where the pair passes. Otherwise use them for non-text elements only.
  3. Take screenshots: desktop light, desktop dark, mobile light, mobile dark.
  4. Check the palette against an official Anthropic source (open item G-B1). If that cannot be done, label the palette unverified in the docs.
- **Dependencies:** P3-09, P3-10, P3-01 (SAD-28).
- **Outputs:** `docs/evidence/P3-11-contrast.md` (each pair with its ratio); screenshots under `docs/evidence/`.
- **Verification:**
  - T-U: automated contrast check on token pairs. Body text at least 4.5:1. Large text and component boundaries at least 3:1.
  - T-M: owner reviews the screenshots.
  - T-M-DEV: screenshots taken on a real phone.
- **Performance:** N/A.
- **Acceptance:**
  - All text pairs pass WCAG AA.
  - No failing pair is used for text.
  - Owner signs off the screenshots.
  - G-B1 is closed, or the docs label the palette unverified.
