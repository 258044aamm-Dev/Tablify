# P2-02 — Filter engine

- **Linear:** SAD-26
- **Phase:** P2 — Query and view state (see `spec/phases/P2.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P2-02)

- **Objective:** A parsed query returns the same rows as a simple reference implementation.
- **Prerequisites:** P2-01, P1-02.
- **Actions:**
  1. Compile each AST term into a predicate using the field type from the registry.
  2. Type mismatch (for example `>n` on a text field) returns a query error, not an empty result.
  3. The builder UI emits a query string through the printer from P2-01, so builder and text query use the same path.
- **Dependencies:** P2-01, P1-02.
- **Outputs:** `src/query/evaluate.ts`, tests, reference implementation in test code only.
- **Verification:**
  - T-D: naive reference evaluator (direct loop over rows) vs. compiled evaluator. 10,000 random queries over FX-M. Zero mismatches required.
  - T-U: 30 hand-written cases with expected row IDs.
  - T-U: type mismatch produces an error.
- **Performance:** PERF-2: filter FX-M < 200 ms p95. Record FX-L for information only.
- **Acceptance:** Zero differential mismatches. Hand cases pass. PERF-2 met on the recorded hardware.
