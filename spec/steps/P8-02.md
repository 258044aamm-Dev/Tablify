# P8-02 — Formula engine

- **Linear:** SAD-61
- **Phase:** P8 — Formulas and linked records (v2) (see `spec/phases/P8.md`)
- **Scope:** v2
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P8-02)

- **Objective:** The engine evaluates formulas exactly as the spec says, with cycle detection and no crashes.
- **Prerequisites:** P8-01, P1-01.
- **Actions:**
  1. Parser and evaluator, pure module.
  2. Dependency graph; topological evaluation; cycle detection.
  3. Recalculate only dependents of changed cells.
  4. Error values (for example divide by zero) are values, not exceptions.
- **Dependencies:** P8-01, P1-01.
- **Outputs:** `src/formula/*`, tests.
- **Verification:**
  - T-U: all golden cases from P8-01 pass.
  - T-F: 10,000 seeded random formula strings. No uncaught exception.
  - T-M: incremental recalculation vs. full recalculation on random edits. Must match.
  - T-U: each formula evaluated once per change (count the calls).
- **Performance:** Recalculate FX-M with 5 formula columns after one edit < 200 ms (proposed).
- **Acceptance:** All golden cases pass. Fuzz clean. Incremental matches full.
