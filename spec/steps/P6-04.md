# P6-04 — Community plugin review checklist

- **Linear:** SAD-47
- **Phase:** P6 — Hardening and release (see `spec/phases/P6.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P6-04)

- **Objective:** The release follows the Obsidian community plugin guidelines in effect at release time.
- **Prerequisites:** P0-02.
- **Actions:**
  1. Copy the current Obsidian plugin developer guidelines into `docs/review-checklist.md` with the date checked and a link.
  2. Check each item. Include from the reference project's review history: settings headings via the Setting heading API, `requestUrl` for network calls, `activeDocument` when working with DOM windows, no leaf detach on unload, no unsafe HTML insertion, no bundled Node-only code.
  3. Run the lint rules and record the result.
- **Dependencies:** P0-02.
- **Outputs:** Checklist with evidence per item.
- **Verification:** Second person reviews the checklist. Each item links to code or a test.
- **Performance:** N/A.
- **Acceptance:** Every checklist item marked done with evidence or marked not applicable with reason. Lint passes.
