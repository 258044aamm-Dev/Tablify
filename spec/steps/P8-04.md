# P8-04 — Linked records

- **Linear:** SAD-63
- **Phase:** P8 — Formulas and linked records (v2) (see `spec/phases/P8.md`)
- **Scope:** v2
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P8-04)

- **Objective:** Links between tables survive renames and show broken links instead of losing data.
- **Prerequisites:** P1-02, P1-03.
- **Actions:**
  1. Link field stores target table ID and target row ID.
  2. Renaming a file or a target row keeps the link (IDs, not names).
  3. Deleting a target row: link shows a broken-link marker; no data removed from the source.
  4. Link integrity check command: lists broken links.
- **Dependencies:** P1-02, P1-03.
- **Outputs:** `src/model/link.ts`, UI, integrity check.
- **Verification:**
  - T-I: rename the target file; link still resolves.
  - T-I: delete a target row; marker shown; source value kept.
  - T-I: integrity check output matches a known set of broken links created by the test script.
- **Performance:** Integrity check on FX-M with 1,000 links < 1,000 ms (proposed).
- **Acceptance:** All checks pass.
