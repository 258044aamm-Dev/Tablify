# P6-02 — Performance verification

- **Linear:** SAD-45
- **Phase:** P6 — Hardening and release (see `spec/phases/P6.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P6-02)

- **Objective:** Measured results against PERF-1 to PERF-8 on recorded hardware.
- **Prerequisites:** P6-01 (for mobile devices), P3-01, P2-02.
- **Actions:**
  1. Follow §0.4 measurement protocol exactly.
  2. Run on the desktop reference machine and on at least one mid-range phone per platform.
  3. Produce a results table: target, measured median, measured p95, pass or fail, hardware.
  4. If a target fails, open an issue. Do not change the target to pass.
  5. Owner confirms or changes each *proposed* target before any public statement uses it.
- **Dependencies:** P6-01.
- **Outputs:** `docs/performance/report-<date>.md`, raw data files.
- **Verification:** Benchmark scripts re-run by a second person; results within a tolerance of 10% of the first run (proposed), otherwise investigate.
- **Performance:** PERF-1 to PERF-8.
- **Acceptance:** Each target has a measured result. Failing targets are either fixed or listed in the release notes as known limitations. Report includes hardware and versions.
