# P6-03 — Accessibility

- **Linear:** SAD-46
- **Phase:** P6 — Hardening and release (see `spec/phases/P6.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P6-03)

- **Objective:** Every MVP action is available from the keyboard, and the grid is usable with a screen reader on desktop.
- **Prerequisites:** P3-06, P5-02.
- **Actions:**
  1. Keyboard-only run-through of every MVP action. Record the list.
  2. Screen reader test: NVDA on Windows and VoiceOver on macOS. Check cell name, column name, row number, and invalid state are announced.
  3. Check focus is visible on every interactive element (contrast ratio measured with a tool).
  4. Automated DOM checks where a tool is available (for example axe-core if used in the UI test harness).
- **Dependencies:** P3-06, P5-02.
- **Outputs:** `docs/accessibility/audit.md`, issues.
- **Verification:** Audit items each marked with result and evidence.
- **Performance:** N/A.
- **Acceptance:** Every MVP action reachable by keyboard. Screen reader results recorded. Open findings are S3 or lower and listed with owner approval.
