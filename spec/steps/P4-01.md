# P4-01 — CSV parser

- **Linear:** SAD-36
- **Phase:** P4 — Import and export (see `spec/phases/P4.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P4-01)

- **Objective:** Correct CSV parsing with streaming-friendly design.
- **Prerequisites:** none.
- **Actions:**
  1. Implement RFC 4180 behavior: quoted fields, doubled quotes, embedded commas and newlines, CRLF and LF.
  2. Strip UTF-8 BOM.
  3. Delimiter detection between `,` and `;` on the first line. Record the rule.
  4. Process in chunks, not one full string copy, to keep memory bounded.
- **Dependencies:** none.
- **Outputs:** `src/io/csv.ts`, tests.
- **Verification:**
  - T-U: RFC 4180 examples and FX-CSV-RFC cases.
  - T-D: differential test against a reference CSV library (test-only dependency). 10,000 random generated CSVs. Zero mismatches.
  - T-F: 10,000 seeded malformed inputs. No uncaught exception.
  - T-P: PERF-5 on 10,000 rows.
- **Performance:** PERF-5.
- **Acceptance:** All tests pass. PERF-5 met on recorded hardware. Mobile timing recorded.
