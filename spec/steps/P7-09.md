# P7-09 — Auto-create Airtable fields

- **Linear:** SAD-58
- **Phase:** P7 — Embeds and Airtable sync (v1.1) (see `spec/phases/P7.md`)
- **Scope:** v1.1
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P7-09)

- **Objective:** Fields are created in Airtable only after the user confirms the exact list.
- **Prerequisites:** P7-05, P7-07.
- **Actions:**
  1. Compute missing fields. Show the list with names and types.
  2. Require explicit confirmation. Default button is Cancel.
  3. Missing `schema.bases:write` scope: clear error, no partial creation.
  4. README and setup doc list the scope (D5).
- **Dependencies:** P7-05, P7-07.
- **Outputs:** `src/sync/autoCreate.ts`, dialog, docs.
- **Verification:**
  - T-I: cancel path creates no field (check Airtable base via API).
  - T-I: confirm path creates exactly the listed fields with matching types.
  - T-I: token without the scope gives the error and creates nothing.
- **Performance:** N/A.
- **Acceptance:** All three paths verified.
