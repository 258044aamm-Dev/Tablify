# P3-03 — Select dropdown and option manager

- **Linear:** SAD-30
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P3-03)

- **Objective:** Users choose or create options without leaving the grid, and manage them in one place.
- **Prerequisites:** P3-02, P1-06.
- **Actions:**
  1. Searchable dropdown. Typing an unknown name offers "Create".
  2. Option manager dialog: rename, recolor, reorder, delete with confirmation.
  3. Test input with IME composition (for example Japanese or Chinese input) and document the result.
- **Dependencies:** P3-02, P1-06.
- **Outputs:** `src/views/grid/select/*`.
- **Verification:**
  - T-E: create-on-type creates exactly one option when typed twice with different case.
  - T-E: rename and recolor persist after reopen.
  - T-E: delete confirmation shows the number of affected cells.
  - T-M-DEV: IME test on desktop and mobile.
- **Performance:** Dropdown opens < 100 ms with 200 options (proposed).
- **Acceptance:** All T-E cases pass. IME result recorded (pass or documented limitation).
