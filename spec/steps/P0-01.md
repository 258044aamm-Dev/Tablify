# P0-01 — Scaffold the plugin

- **Linear:** SAD-15
- **Phase:** P0 — Foundation and format spec (see `spec/phases/P0.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P0-01)

- **Objective:** A plugin that loads, shows in the plugin list, and does nothing harmful.
- **Prerequisites:** Repository created; Node LTS; decision on TypeScript and esbuild (locked by roadmap).
- **Actions:**
  1. Create the repo with `manifest.json` (`id: tablify`, `name: Tablify`, `isDesktopOnly: false`, `version: 0.0.1`).
  2. Add `main.ts` that registers one no-op command.
  3. Add the esbuild config. Output `main.js` in the repo root.
  4. Set `minAppVersion` to the lowest version that supports every API used. Record which API calls drove that choice.
  5. Commit `package-lock.json`.
- **Dependencies:** none.
- **Outputs:** Repo skeleton, manifest, build script, `docs/decisions/min-app-version.md`, evidence file.
- **Verification:**
  - T-U: a test that parses `manifest.json` and asserts `id`, `name`, `isDesktopOnly`, `minAppVersion` are present and correct.
  - T-I: install into the desktop test vault, enable, confirm the command appears. Check the developer console for errors.
  - T-M-DEV: enable on iOS and Android. Record the result.
- **Performance:** Record `main.js` size as the baseline. No target yet. Plugin load time recorded for information only.
- **Acceptance:** Plugin loads on desktop and mobile with no console errors. `minAppVersion` is backed by a written reason. Build reproducible from a clean clone (verified by a second clone and identical `main.js` hash).
