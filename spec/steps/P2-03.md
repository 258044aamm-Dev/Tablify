# P2-03 — View state

- **Linear:** SAD-27
- **Phase:** P2 — Query and view state (see `spec/phases/P2.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P2-03)

- **Objective:** View settings save and reload exactly, and never crash when a referenced field no longer exists.
- **Prerequisites:** P1-03.
- **Actions:**
  1. Define the view object: sort list, group field, hidden field IDs, column order and widths, frozen column count, row height.
  2. Validate on load: unknown field IDs are ignored with a warning recorded in the view, not an error.
  3. Reject hiding the primary field (R-D13).
- **Dependencies:** P1-03.
- **Outputs:** `src/model/view.ts`, tests.
- **Verification:**
  - T-U: each setting save and reload.
  - T-U: view referencing a deleted field loads without error and the warning is recorded.
  - T-I: change settings in a real vault, restart Obsidian, confirm settings restored.
- **Performance:** N/A.
- **Acceptance:** All tests pass. Restart test passes and is recorded.
