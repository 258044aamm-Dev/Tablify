# P3-08 — Filter bar

- **Linear:** SAD-35
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P3-08)

- **Objective:** Search, query input, builder, and sort menu work together and stay in sync.
- **Prerequisites:** P2-02, P2-03.
- **Actions:**
  1. Search box: free text across text fields.
  2. Query input: parsed on change, errors shown inline below the input.
  3. Builder: adds and removes filter rows; output updates the query input.
  4. Debounce input by 200 ms (proposed).
- **Dependencies:** P2-02, P2-03.
- **Outputs:** `src/views/grid/toolbar.ts`, tests.
- **Verification:**
  - T-E: type a query with an error; error shows; fix it; error clears.
  - T-E: builder change updates query text; text change updates builder.
  - T-P: keystroke to filtered result on FX-M < 200 ms p95 (PERF-2).
- **Performance:** PERF-2.
- **Acceptance:** All checks pass.
