# P4-04 — Import command

- **Linear:** SAD-39
- **Phase:** P4 — Import and export (see `spec/phases/P4.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P4-04)

- **Objective:** Import creates a complete, correct `.tablify` file, or nothing.
- **Prerequisites:** P4-03, P1-03.
- **Actions:**
  1. Command "Import CSV / Excel as table" opens a file picker (desktop) or the file selection available on mobile.
  2. Build the table in memory, validate, serialize, then write. Write only after full success (atomic).
  3. Name collision: append a number (for example `Tasks 2.tablify`). Never overwrite.
  4. Open the new file.
- **Dependencies:** P4-03, P1-03.
- **Outputs:** `src/commands/import.ts`, tests.
- **Verification:**
  - T-I: import a 500-row CSV and a 500-row XLSX. A script compares row count and every cell value against the source.
  - T-I: force a serialization error (test hook). Confirm no file is written.
  - T-I: collision test.
  - T-P: PERF-6 for FX-M (1,000 rows).
- **Performance:** PERF-6.
- **Acceptance:** Scripted comparison reports zero mismatches on both files. Failure test leaves no partial file. PERF-6 met.
