# P3-07 — Column and row layout

- **Linear:** SAD-34
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P3-07)

- **Objective:** Column and row layout changes are saved and survive reopen.
- **Prerequisites:** P3-01, P2-03.
- **Actions:**
  1. Resize by dragging the header edge. Minimum width 60 px (proposed).
  2. Reorder by drag. Provide a keyboard alternative (move left or right).
  3. Freeze the first N columns. Frozen columns stay visible during horizontal scroll.
  4. Row height setting (compact, medium, tall). Applies to all rows.
- **Dependencies:** P3-01, P2-03.
- **Outputs:** `src/views/grid/columns.ts`, tests.
- **Verification:**
  - T-E: change each setting, reopen, confirm.
  - T-E: freeze behavior visually confirmed with horizontal scroll on FX-M.
  - T-E: keyboard reorder works.
- **Performance:** Drag updates at p95 ≤ 33 ms per frame (proposed).
- **Acceptance:** All checks pass.
