# P1-06 — Select options

- **Linear:** SAD-24
- **Phase:** P1 — Data core (see `spec/phases/P1.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P1-06)

- **Objective:** Options are created, renamed, reordered, and deleted with correct references.
- **Prerequisites:** P1-01.
- **Actions:**
  1. Option has a stable ID, a display name, and a color from a fixed palette.
  2. Create-on-type matches existing options by trimmed, case-insensitive name. If none matches, create one.
  3. Rename changes the name only; the ID stays.
  4. Delete clears the option from all cells that use it (R-D12). Implement as one undoable command.
- **Dependencies:** P1-01, P1-05 (delete must be undoable).
- **Outputs:** `src/model/selectOptions.ts`, tests.
- **Verification:**
  - T-U: create-on-type with same name in different case returns the existing option.
  - T-U: rename keeps references valid.
  - T-M: delete then undo restores every affected cell.
- **Performance:** N/A.
- **Acceptance:** All tests pass. Delete-undo round trip exact.
