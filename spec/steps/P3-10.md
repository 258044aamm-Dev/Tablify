# P3-10 — Bundle and load fonts (Poppins, Lora)

- **Linear:** SAD-66
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/branding.md` §4, `spec/guidelines.md` §0 and §1
- **Source:** written for this spec from `spec/branding.md` §4 (owner decision: bundle the fonts). Not in the guideline file.

- **Objective:** Headings use Poppins and body text uses Lora, with fallbacks. The fonts look the same on desktop and mobile, and they work offline.
- **Prerequisites:** P3-09 (token and theme definitions).
- **Actions:**
  1. Add Poppins and Lora font files (woff2) to `assets/fonts/`.
  2. Add `@font-face` rules to the plugin styles.
  3. Set fallback stacks: Arial for headings, Georgia for body text.
  4. Add the SIL Open Font License text as `LICENSE-FONTS` and ship it with the release.
  5. Record the plugin bundle size before and after the change.
- **Dependencies:** P3-09.
- **Outputs:** font files; `@font-face` rules; `LICENSE-FONTS`; bundle size record in `docs/evidence/P3-10.md`.
- **Verification:**
  - T-M-DEV: on a phone in airplane mode, the fonts render.
  - T-M: desktop network log shows no font requests to external hosts.
  - T-U: the manifest and build output list the font files and the license.
- **Performance:** The table is visible with the fallback font while the bundled font loads. The first render still meets PERF-1 (proposed).
- **Acceptance:**
  - Fonts load offline on desktop and mobile.
  - `LICENSE-FONTS` is present in the build.
  - The bundle size change is recorded in evidence.
