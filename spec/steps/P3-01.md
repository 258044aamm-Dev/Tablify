# P3-01 — Grid shell with virtual rows

- **Linear:** SAD-28
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P3-01)

- **Objective:** Render only visible rows, with stable scrolling and no growth in DOM size.
- **Prerequisites:** P1-02.
- **Actions:**
  1. Fixed row height per row-height setting; compute visible range from scroll position.
  2. Recycle row elements. Overscan of a small number of rows (document the number).
  3. Column virtualization is optional. Decide and record. If not implemented, document the column limit that stays smooth (measure).
  4. Support touch scrolling on mobile without blocking the page.
- **Dependencies:** P1-02.
- **Outputs:** `src/views/grid/*`, tests, benchmark script.
- **Verification:**
  - T-I: count DOM row elements on FX-M while scrolling. Must stay at visible rows plus overscan.
  - T-P: PERF-4 frame time during a scripted scroll on FX-M.
  - T-P: PERF-8 heap after 10 minutes of scroll and edit cycles.
  - T-M-DEV: scroll on a mid-range phone; record.
- **Performance:** PERF-4 and PERF-8.
- **Acceptance:** DOM count bounded. PERF-4 and PERF-8 met on recorded hardware. Device scroll recorded.
