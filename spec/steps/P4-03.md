# P4-03 — Type inference

- **Linear:** SAD-38
- **Phase:** P4 — Import and export (see `spec/phases/P4.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P4-03)

- **Objective:** Column types inferred from values, with documented rules and measured accuracy on a labeled set.
- **Prerequisites:** P4-01, P4-02, P1-01.
- **Actions:**
  1. Build a labeled test set: at least 30 columns with known intended types (text, number, date, checkbox, single select), 100 values each, including noisy values.
  2. Rules: date formats accepted (state them), number with locale-free decimal point (assumption G-A5), checkbox from true/false/yes/no/1/0, single select when distinct values ≤ 20 and ≤ 50% of rows (proposed thresholds, record them).
  3. Ambiguous columns default to text.
- **Dependencies:** P4-01, P4-02, P1-01.
- **Outputs:** `src/io/infer.ts`, labeled set, accuracy report.
- **Verification:**
  - T-U: each rule has tests.
  - Accuracy: per-type precision and recall on the labeled set, reported with the actual numbers. Acceptance threshold: at least 90% of columns inferred as labeled (proposed). Do not report a result above the measured number.
- **Performance:** Inference on FX-XLSX < 500 ms (proposed).
- **Acceptance:** Threshold met or owner accepts the measured result. Known misclassifications listed.
