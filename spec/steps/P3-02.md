# P3-02 — Cell editors

- **Linear:** SAD-29
- **Phase:** P3 — Grid UI (see `spec/phases/P3.md`)
- **Scope:** MVP
- **Read first:** `spec/glossary.md`, `spec/guidelines.md` §0 (rules) and §1 (assumptions), `spec/roadmap.md` §3 (decisions)
- **Source:** copied unchanged from `spec/guidelines.md` (section for P3-02)

- **Objective:** Each field type can be edited, validated, and saved through a command.
- **Prerequisites:** P3-01, P1-01.
- **Actions:**
  1. One editor per type. Enter commits, Escape cancels, blur commits.
  2. Every commit goes through a P1-05 command.
  3. Read-only types show no editor.
  4. Invalid input: keep editor open, show the error, do not write.
- **Dependencies:** P3-01, P1-01, P1-05.
- **Outputs:** `src/views/grid/editors/*`.
- **Verification:**
  - T-E: for each type, edit a cell, press Enter, confirm the value in the file on disk.
  - T-E: Escape leaves the file unchanged.
  - T-E: invalid input does not change the file.
  - T-U: each editor's commit calls the command path (spy test).
- **Performance:** Edit commit < 50 ms on FX-M (proposed).
- **Acceptance:** All T-E cases pass for every type. Evidence includes before and after file contents.
