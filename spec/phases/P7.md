# Phase 7 — Embeds and Airtable sync (v1.1)

**Phase objective:** Optional Airtable sync and embedded tables, with no secret leaks and no silent data overwrite.

**Phase prerequisites:** 1.0 released (Phase 6 gate passed). Dedicated Airtable test base and personal access token for test use only, stored outside the repo. Airtable API docs checked and the version recorded (G-A3).

### Phase 7 gate and assumption register

- **Gate:** P7-01 through P7-10 accepted. Security review of token handling (P7-03 evidence). Gate note `docs/gates/phase-7.md`.
- **Assumptions and limitations:**
  - Airtable behavior and limits are as documented at the recorded docs version (G-A3).
  - Live tests depend on a test base and external service availability. Failures due to the service are recorded as NOT RUN, not as passes.
  - Conflict handling is limited to the decision table. No automatic merge within a field.
  - Sync is manual only. No background sync.
