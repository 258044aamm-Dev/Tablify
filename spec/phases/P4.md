# Phase 4 — Import and export

**Phase objective:** Import and export that preserve data, with tests against independent references.

**Phase prerequisites:** Phase 3 gate passed (for UI steps). P4-01 and P4-02 can start earlier.

### Phase 4 gate and assumption register

- **Gate:** P4-01 through P4-05 accepted. Gate note `docs/gates/phase-4.md`.
- **Assumptions and limitations:**
  - XLSX formulas are imported as cached values only.
  - Date inference rules are documented and may misclassify ambiguous dates (for example 01/02/2026). Listed in the accuracy report.
  - Export of merged cells or styles is not supported.
