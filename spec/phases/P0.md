# Phase 0 — Foundation and format spec

**Phase objective:** A buildable, lintable, testable plugin skeleton, a written format spec, and proof that `.tabula` is ignored.

**Phase prerequisites:** Node LTS installed; an Obsidian desktop test vault; a mobile test device or the ability to sideload via Obsidian Sync or a dev folder; owner decisions D-O4 (min version) recorded when P0-01 completes.

### Phase 0 gate and assumption register

- **Gate:** P0-01 through P0-04 accepted. `check` green. Gate note `docs/gates/phase-0.md`.
- **Assumptions and limitations:**
  - The spec is a v1 contract. Changes after release require a `formatVersion` bump (R11).
  - Obsidian's file-type registration behavior is assumed to match the documentation of the tested version. Verified by T-I.
