# Phase 1 — Data core

**Phase objective:** A pure, tested data model for fields, rows, validation, undo, select options, and file read/write.

**Phase prerequisites:** Phase 0 gate passed. Fixtures FX-S and FX-M generated and committed.

### Phase 1 gate and assumption register

- **Gate:** P1-01 through P1-06 accepted. Regression: all Phase 0 tests pass. Gate note `docs/gates/phase-1.md`.
- **Assumptions and limitations:**
  - Currency is stored as integer minor units. Currency code and rounding rules must be in the spec (update P0-03 if not).
  - Unique checks are case-sensitive by default.
  - Coalescing window of 1 second is a default, not measured from users.
  - No formula or link types exist yet.
