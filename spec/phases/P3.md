# Phase 3 — Grid UI

**Phase objective:** A grid that is responsive on FX-M, edits data through commands, and works with keyboard and touch.

**Phase prerequisites:** Phase 2 gate passed. UI test approach from P0-02 selected.

### Phase 3 gate and assumption register

- **Gate:** P3-01 through P3-08 accepted, and P3-09 through P3-11 (UI steps, added for this spec) accepted. Gate note `docs/gates/phase-3.md`. Scripted UI cases executed on desktop (Windows, macOS, Linux) at least once each. Mobile smoke test may be deferred to P6-01.
- **Assumptions and limitations:**
  - Column virtualization may not be implemented. The column limit is measured and documented, not assumed.
  - IME behavior varies by platform. Results are recorded per platform.
  - Clipboard format is tab-separated text only. Rich clipboard formats are out of scope.
