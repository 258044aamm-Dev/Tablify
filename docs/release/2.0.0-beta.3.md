# Tablify 2.0.0-beta.3 — Export destination update

- **Release date:** 2026-10-16
- **Tag:** `v2.0.0-beta.3`
- **Channel:** Pre-release
- **Minimum Obsidian version:** 1.14

## Highlights

- File exports are saved outside the Obsidian vault using a save-location picker, with the table name and format prefilled and Downloads as the starting location where supported.
- On platforms without the picker, Tablify uses a share sheet for shareable mobile files or starts a browser/Electron download. It never silently falls back to writing an export into the vault.
- The default current-view export follows saved search/query, sort, visible fields, and column order. Full table remains unfiltered and includes every field and row.
- CSV, XLSX, and Markdown exports include computed formula values. Pending edits are saved before the modal reads the source file, and read/save/cancel failures receive explicit feedback.
- **Copy current view as Markdown** remains a separate clipboard command.

## Compatibility and known limitations

This release does not change the `.tablify` file format. Tables using formula or link fields still require a Tablify version that supports format version 2; Tablify 1.0.2 and earlier cannot open those files. Update every device before using formula or link fields.

The native picker, mobile share sheet, and platform overwrite/collision behavior were not manually tested inside Obsidian desktop or on a mobile device for this release. The fallback path is explicit and does not write exports into the vault. Please verify the picker/share/download behavior on your target platform before relying on it for important files.

## Rollback

To return to 2.0.0-beta.2, download its `main.js`, `manifest.json`, and `styles.css` assets and replace those files in the plugin folder. The export-destination change does not modify `.tablify` files. Keep Tablify 2.x installed for any table containing formula or link fields.
