# Tablify 2.0.0-beta.7 — Long cell reading, mobile toolbar swipe cues, mobile exports, and attachment file picker

- **Release date:** 2026-10-24
- **Tag:** `v2.0.0-beta.7`
- **Channel:** Pre-release
- **Minimum Obsidian version:** 1.14
- **File format:** unchanged (no migration; `formatVersion` rules are the same as beta.5 and beta.6)

## Highlights

Seven key features and refinements land in this beta release (`SAD-376`, `SAD-375`, `SAD-350`, `SAD-354`, `SAD-355`, `SAD-356`, `SAD-353`):

- **A long cell can be read in full, without losing its ellipsis (SAD-376).** A cell whose text is
  longer than the limit (80 characters by default, counted after formatting and chips) now offers
  the rest of its value. Hovering the cell reveals a small ⤢ in its top-right corner: clicking it
  opens the whole text in the floating panel with **Copy content**; resting on it for a moment
  opens a compact preview card with copy and expand in its corner. On touch devices, the control
  sits in the corner of a long cell and **Expand cell** joins the cell menu. Settings under
  **Settings → Tablify → Cells** configure control visibility and limits.
- **The mobile toolbar now says it can be swiped (SAD-375).** On phones (`≤ 639px`) the tool row
  scrolls horizontally three tools at a time. Soft card-coloured gradient fades sit over the row's
  scroll edges when tools remain off-screen to guide new users to the gesture, honoring *Reduce motion*.
- **Export now works on mobile devices (SAD-350).** Exports now use platform-native capabilities:
  **Android** uses the system "Save as" dialog where the WebView supports it, and otherwise saves
  directly to the shared `Download/Tablify` folder through the Capacitor bridge; **iOS** pre-builds
  the file to open the system sheet (**Save to Files**). Distinguishes dialog dismissals from
  unavailable pickers, with an opt-in vault fallback setting.
- **Rating field visual design refresh (SAD-354).** Cell visual refresh with 12px stars, refined
  spacing and visual hierarchy, touch panel support, empty state cues, and read-only styling.
- **Default country pop-up redesign & 245 country flags (SAD-355).** Country popover matches the
  field width with an aligned grid, sticky group headings, borderless search header band, and 245
  bundled vector flag SVGs with zero external network requests.
- **Attachment cells can take files directly from your device (SAD-356).** Empty and filled
  Attachment cells provide a **Choose a file…** option that opens your device's file picker and
  copies the selected file into the Obsidian vault, updating the cell with the vault-relative path.
- **Field type picker search focus restored (SAD-353).** Search box inside the field type picker
  mounts inside the modal window element so it can be typed into directly on recent Obsidian versions.

## Compatibility and known limitations

This release does not change the `.tablify` file format. Tables using formula or link fields
continue to be saved as format version 2 and cannot be opened by Tablify 1.0.2 or earlier.
A table written by beta.6 opens seamlessly in beta.7 and vice versa.

## Installing on a device

1. Download `main.js`, `manifest.json`, and `styles.css` from the release page.
2. Place them in `<vault>/.obsidian/plugins/tablify/`, replacing any existing files.
3. In Obsidian: **Settings → Community plugins**, toggle **Tablify** off and on (or reload Obsidian).
4. For mobile, place the three files into `<vault>/.obsidian/plugins/tablify/`.
   BRAT users can add `MakeTheNewHistory/Tablify` and pin tag `v2.0.0-beta.7`.

## Rollback

To return to 2.0.0-beta.6, download its `main.js`, `manifest.json`, and `styles.css` assets and
replace the files in the plugin folder. No tables or user data are rewritten in an incompatible way.
