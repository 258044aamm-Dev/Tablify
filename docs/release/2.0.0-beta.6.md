# Tablify 2.0.0-beta.6 — Inline cell image rendering, interactive star ratings, phone country E.164, and mobile layout refinements

- **Release date:** 2026-10-20
- **Tag:** `v2.0.0-beta.6`
- **Channel:** Pre-release
- **Minimum Obsidian version:** 1.14
- **File format:** unchanged (no migration; `formatVersion` rules are the same as beta.5)

## Highlights

Seven tickets ride in this beta (`SAD-347`, `SAD-304`, `SAD-303`, `SAD-305`, `SAD-306`, `SAD-307`, `SAD-308`):

- **Inline image thumbnails and lightbox preview in Attachment cells (SAD-347).** When an
  **Attachment** cell points to a supported image in your vault (`.png`, `.jpg`, `.jpeg`, `.gif`,
  `.webp`, `.svg`, `.bmp`, `.avif`, `.ico`), its chip now renders a rounded inline thumbnail
  beside the filename, scaled for **Small** (`16×16` in `28px`), **Medium** (`20×20` in `34px`)
  and **Large** (`26×26` in `40px`) row heights without changing row pitch or virtual-scroll math.
  Clicking the thumbnail opens a themed lightbox dialog (`ImagePreviewModal`) with the full-size
  image and its dimensions (`{path} · {width} × {height} px`); clicking or double-clicking the rest
  of the cell selects or edits as before, and the **Attachments** panel also shows a clickable
  preview banner above the file row. Missing vault files or broken images fall back automatically
  to the paperclip chip with the filename intact. Works in both the full `.tablify` view and note
  embeds.
- **Ratings are stars you can click, with fractional fill and a slider panel (SAD-304).** A
  **Rating** cell draws one star per point of the field's **Max** and fills each by the value's
  fraction (`4.5` is four full stars and half of the fifth), followed by the number. Clicking a
  star writes that value in one undo step, and hovering lights the stars up to the pointer.
  Double-click or **Enter** opens a panel with half-star zones, drag-to-scrub, a numeric field for
  any decimal (`3.7`), and full keyboard/screen-reader slider support. Airtable pushes round to
  whole stars and report how many ratings were rounded while keeping the fractional value in your
  `.tablify` file.
- **Phone fields have a default country, store E.164, and infer on import (SAD-303).** A **Phone**
  field can set a searchable **Default country** in *Add New Field* / *Modify Field*. Editing a
  phone cell opens an anchored country + number panel that formats as you type, previews the
  international form, and saves canonical **E.164** (`+8801712345678`) while displaying
  `+880 1712 345678` in the grid. CSV and XLSX imports now recognise email, URL and phone columns
  and preserve them across export/import round-trips.
- **Mobile editing, toolbar scrolling, search placeholder, and bottom-bar clearance (SAD-305,
  SAD-306, SAD-307, SAD-308).** Opening the on-screen keyboard on mobile no longer collapses the
  table (`SAD-305`); the search input adapts its placeholder with clean ellipsis truncation on
  narrow screens (`SAD-306`); `TableView` measures Obsidian's `.mobile-navbar` and safe-area inset
  so the **Insert Row** button always scrolls into view above the mobile bottom bar (`SAD-307`);
  and the toolbar orders **Undo, Redo, Add Field, Add Row, Filter, Sync, Options** with 3-tool
  horizontal scrolling on mobile viewports (`SAD-308`).

## Compatibility and known limitations

This release does not change the `.tablify` file format. Tables using formula or link
fields are still saved as format version 2 and cannot be opened by Tablify 1.0.2 or
earlier; update every device before using those fields. The optional `defaultCountry`
key on Phone fields is additive. A table written by beta.5 opens unchanged in beta.6 and
the reverse is true as well.

## Installing on a device

1. Download the three assets above from the release page.
2. Put them in `<vault>/.obsidian/plugins/tablify/`, replacing the existing files.
3. In Obsidian: **Settings → Community plugins**, then disable and re-enable **Tablify**
   (or reload the app) so the new `main.js` is loaded.
4. On mobile, the plugin folder lives inside the vault's `.obsidian/plugins/` directory;
   the same three files apply. BRAT users can add `MakeTheNewHistory/Tablify` (or
   `258044aamm-Dev/Tablify`) and pin tag `v2.0.0-beta.6`.

## Rollback

To return to 2.0.0-beta.5, download its `main.js`, `manifest.json`, and `styles.css`
assets and replace those files in the plugin folder. Nothing in this release rewrites
existing tables in an incompatible way — keep Tablify 2.x installed for any table that
contains formula or link fields.
