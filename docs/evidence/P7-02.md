## Rules applied

- Every call goes through Obsidian's `requestUrl` (`throw: false`). A test confirms the production default transport uses it.
- **Rate limit.** Airtable documents 5 requests per second per base and 50 per second per token (checked 2026-10-10, airtable.com/developers/web/api/rate-limits). Our spacing is **250 ms per base (4 req/s)**, below the documented 5.
- **429.** Honors `Retry-After` in seconds, capped at 60 s. Without the header, waits 30 s, as Airtable's docs describe. Up to 4 attempts in total, then `rate_limited`.
- **5xx and network errors.** Backoff 1 s, 2 s, 4 s, capped at 8 s. 4 attempts in total.
- **Other 4xx.** No retry: 401 `unauthorized`, 403 `forbidden` (scope hint), 404 `not_found`, other `bad_request`.
- **Pagination.** Follows `offset` until none is returned. A repeated offset or more than 10,000 pages gives `bad_response`, so the loop cannot run forever.
- **Writes.** Batched by 10, the documented limit for create and update.
- **Field keys.** Reads use `returnFieldsByFieldId=true`, so renames do not break mapping (used by P7-05).
