## Rules applied

- **Plugin data only.** The token goes through `saveData`, which writes Obsidian's `data.json` for the plugin. It is not written to `.tablify` files or exports. The token-to-file test confirms this.
- **Masked input.** The input is `type="password"` with `autocomplete="off"` and `spellcheck=false`.
- **Headings.** The settings tab uses `Setting().setHeading()`, per the P6-04 review checklist.
- **Never logs.** No logging. A capture test covers the settings path.
- **Trimmed and bounded.** Input is trimmed. Tokens over 512 characters are treated as empty.
- **Unknown keys are dropped** on load and save, so only the known setting is ever written.
- **Read errors fall back to defaults**, so a broken data file never stops plugin load.
