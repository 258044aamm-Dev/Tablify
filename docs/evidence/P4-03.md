## 1. Labeled set (C1 and C5)

- **C1 applied:** the guidelines' size (30 columns × 100 values with noise) was used, not the roadmap's 10 columns.
- **C5 disclosed:** the agent wrote this set, so it is not independent of the rules. Results are reported as measured, and the report says so.
- Noise is realistic: `N/A`, `tbd`, `1,234.50`, `maybe`, `???`, and blank cells.
- Hard cases were included on purpose: `Comment` (few distinct values, intended text), `Team` (25 options), `Birthday` (ambiguous-only dates), `Approved` (Y/N outside the spec word list), `Shipped` (dd/mm with day > 12, which is unambiguous and should be a date).

## 2. Rules implemented

Applied in order, first match wins. Empty cells (null, undefined, empty or whitespace-only text) are ignored.

1. **checkbox:** every value is a boolean, text true/false/yes/no/1/0 (case-insensitive), or number 0/1.
2. **number:** every value is a finite number, or text matching `[+-]?(digits[.digits?] | .digits)([eE][+-]?digits)?`. Decimal point only (G-A5).
3. **date:** every value is a Date (UTC components), or text in: `YYYY-MM-DD`, `YYYY/MM/DD`, `D Mon YYYY` / `D Month YYYY`, or `A/B/YYYY` and `A.B.YYYY` when one part > 12. Both parts ≤ 12 is **ambiguous, not a date** (G-P3). Must be a valid calendar date.
4. **single_select:** distinct ≤ 20 **and** distinct / non-empty ≤ 0.5. Thresholds are *proposed* (G-P3). Values are compared trimmed.
5. **text:** everything else, including all ambiguous columns.

Default is **strict**: a type applies only when 100% of non-empty values match. Any other result would lose or change cells on import. A `tolerance` option exists for sensitivity analysis only.

## 7. Known misclassifications (for the import report, P4-04)

1. Ambiguous-only dates (`01/02/2026`) are text. Users must reformat.
2. Noisy numeric and date columns are text under strict rules.
3. Columns with 0/1 only are checkbox (spec-literal). A numeric 0/1 column becomes a checkbox.
4. Y/N, and other words outside the spec list, are not checkbox.
5. Columns with few distinct values are single_select even when intended as text (`Comment`).
