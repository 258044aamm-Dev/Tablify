## Deviations

- **Duplicate field IDs and unknown row field references:** These are semantic constraints that cannot be fully expressed in JSON Schema alone (Schema validates the structure but cannot enforce cross-array uniqueness or cross-object references). The test file includes application-level semantic checks for these cases. Full enforcement will be implemented in P1-03 (parser/serializer).
