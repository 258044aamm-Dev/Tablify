  @font-face { font-family: 'Poppins'; src: url('assets/fonts/Poppins-Regular.woff2') format('woff2'); font-weight:400; font-display:swap; }

  Fallback stacks: headings `Poppins, Arial, sans-serif`; body `Lora, Georgia, serif`. Uses `font-display: swap` so first render shows fallback quickly and still meets PERF-1 (proposed).

## Coverage notes

- Only woff2 latin subsets are shipped (smallest useful subset, 7–23 KB each). Other subsets (cyrillic, latin-ext) are available in `@fontsource` but not committed to keep the plugin zip small.
- Fallback stacks per branding.md §4: headings Arial, body Georgia — ensures first paint meets PERF-1 even before woff2 loads.
- `font-display: swap` guarantees table is visible with fallback while bundled font loads — required for offline and for first-render perf.
- License hygiene: `LICENSE-FONTS` contains the full OFL v1.1 text for both families, as required for release. P6-06 will re-verify OFL terms before store submission.

## Decisions

- Used `@fontsource` npm packages as the woff2 source rather than scraping fonts.google.com zip — deterministic, versioned, and already SIL OFL licensed. Alternative was curling Google Fonts API, but npm gives file integrity and license file directly.
- Kept `@fontsource` in `devDependencies` (not shipped) and committed only the 4 needed woff2 files to `assets/fonts/` — keeps plugin zip small vs committing dozens of subsets. Owner may later switch to full variable fonts if desired, but current 4 files cover the spec (headings + body + italic).
- Weight choice: Poppins 400 (Regular) + 600 (SemiBold) covers headings (normal + bold), Lora 400 + 400 italic covers body and emphasis. Other weights (700, 500) are available but not needed for MVP.
