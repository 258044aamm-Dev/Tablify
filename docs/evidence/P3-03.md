## Objective

Users choose or create options without leaving the grid, and manage them in one place.

## Deliverables

- `src/views/grid/select/Dropdown.ts` — searchable dropdown, case-insensitive filter via `name.toLowerCase().includes`, offers `Create "raw"` when no filtered match, `compositionstart/end` guards (IME), `Enter` commits via `findOrCreate` (dedup), `Escape` closes
- `src/views/grid/select/OptionManager.ts` — dialog logic `rename(id,newName)` + `recolor(id,color)` + `reorder(ids)` + `getDeleteAffectedCount(id)` (scans store for single/multi) + `confirmDelete` (calls `manager.delete` which clears cells R-D12)
- `tests/views/grid/select.test.ts` — 5 tests (jsdom):
  - create-on-type once with different case
  - rename/recolor persists after reopen (field mutated)
  - delete shows affected count (2 cells) and clears them
  - IME composition does not commit on Enter during composition, does after
  - dropdown opens <100 ms with 200 options (proposed) — measured via `performance.now`
