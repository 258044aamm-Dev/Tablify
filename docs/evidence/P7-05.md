## Decisions recorded in the code

- Tablify field ID is `fld_` plus the Airtable ID body. Airtable field IDs never change on rename, so this stays stable.
- Read-only in Tablify (shown, never pushed): dateTime (time zone not verified), duration (unit conversion not verified), attachments (shown as file names in a text column), auto number, created and modified time, rating above 10, and all unsupported types.
- Unsupported types (rich text, formula, rollup, count, lookup, record links, collaborators, created or modified by, barcode, button, aiText, external sync source) become a read-only text column. The original type name is kept in `airtable.type`.
- Select colors map by family (blue, cyan, teal → blue). An unknown color maps to gray.
- Collisions: `fld-A` and `fld_A` both derive `fld_A`, so the second gets a numeric suffix. The test expectation was wrong and is now corrected to the derived IDs (`fld__A`, `fld__A_2`). `fldA` and `fld-A` do not collide.
