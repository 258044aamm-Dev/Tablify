What this fixes, and the numbers behind it

Today (native)In the panel
Chromium draws the calendar; it ignores Obsidian's theme, so it is a bright white sheet in dark mode, with the OS's own radius, grey, and year arrows. The plugin draws it from the same tokens as the grid — --tablify-bg-pill, --tablify-accent-primary, --tablify-text — so it is themed, and it matches the select/attachment cards.
The field is datetime-local: two spinners inside a 16 px capsule, pill height, no room for the value. A 30 px field, mono 11.5 px, the value left-aligned with 10 px padding; the time lives on its own row instead of inside the field.
No shortcut for "today", no way to clear, no visible month once you scroll away. Today, Clear, and for date & time Now; the month is always named in the header.
Clicking the tiny glyph is the only way to open a calendar, and on touch the OS picker takes over. The whole cell opens the same panel (double-click, Enter, second tap), anchored 6 px under the cell, flipped above it when near the bottom edge.

Keyboard. Tab walks field → chevrons → grid → time → footer. Arrows move by day/week, PageUp/Down change month, Home/End jump to the week's ends, Enter picks, Escape closes and discards, Alt+↓ opens from the grid. Day cells are buttons with a roving tabindex; the month change is announced in a polite live region.

Commit. Everything in the card edits a draft. Done or a click outside writes it as one undo step; Escape throws the draft away; picking a day in a date field commits and closes immediately (there is no time to add). A draft equal to the stored value writes nothing — the same no-op rule COD-68 established.

Fonts in this mock fall back to the system stacks — the preview sandbox has no network. In the plugin the chrome is Poppins and every value/time digit is JetBrains Mono, both embedded in styles.css.
